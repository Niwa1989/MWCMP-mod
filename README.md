# My Winter Car — мультиплеер (сборка)

> Готовое решение для совместной игры в My Winter Car через мод, собранный из исходников.


## ⚠️ Авторство

Исходный код мода принадлежит **tudorek12345**:  
[https://github.com/tudorek12345/my-winter-car-mp-mod](https://github.com/tudorek12345/my-winter-car-mp-mod)

Загрузчик модов **BepInEx**:  
[https://github.com/BepInEx/BepInEx/releases](https://github.com/BepInEx/BepInEx/releases)

**Этот репозиторий не является оригинальным модом.**  
Я лишь собрал исходники в готовый `.dll`, чтобы вам не пришлось делать это самостоятельно.


## 🎮 Для игроков (готовое решение)

**1. Скачайте BepInEx**  
Перейдите по ссылке: BepInEx releases, скачайте версию **BepInEx_win_x64_X.X.X.X.zip** и распакуйте содержимое архива **в папку с игрой** (где лежит `MyWinterCar.exe`).

**2. Настройте BepInEx**  
Запустите игру через Steam, чтобы BepInEx создал служебные папки. Игра может не запуститься — это нормально. Откройте файл `BepInEx/config/BepInEx.cfg`, найдите строку **`Type = Application`** и замените её на **`Type = MonoBehaviour`**. Сохраните файл. Запустите игру и выйдите из неё, чтобы папки и конфиги создались окончательно.

**3. Установите мод**  
Скачайте файл **`MyWinterCarMpMod.dll`** из этого репозитория (вкладка **Releases** или в корне проекта) и скопируйте его в папку `BepInEx/plugins/`.

**4. Запустите игру**  
Запускайте My Winter Car через Steam. В игре появится мультиплеер. Настройки по умолчанию могут быть сырыми — их можно изменить (см. пункт 5).

**5. Настройка параметров мода**  
Откройте папку `BepInEx/config/`, найдите файл **`com.tudor.mywintercarmpmod.cfg`** и отредактируйте настройки под себя.


## 🛠️ Для разработчиков (сборка из исходников)

Если вы хотите собрать мод самостоятельно:

**1. Скачайте исходники**  
Выполните команду: **git clone https://github.com/tudorek12345/my-winter-car-mp-mod**

**2. Укажите путь к игре**  
Откройте файл **src/MyWinterCarMpMod.csproj** (через блокнот). Найдите строку GameDir Condition=" '$(GameDir)' == '' ">ЗДЕСЬ_ПУТЬ</GameDir и замените ЗДЕСЬ_ПУТЬ на путь к папке с игрой, например **C:\Program Files (x86)\Steam\steamapps\common\MyWinterCar. Сохраните файл.

**3. Соберите проект**  
Откройте **my-winter-car-mp-mod.sln** в Visual Studio (или VS Code с C#). Нажмите **Ctrl + Shift + B** (или выберите **«Собрать решение»**). Если сборка успешна, вы увидите **Сборка: успешно — 1, сбоев — 0**.

**4. Заберите .dll**  
Файл появится по пути **src/MyWinterCarMpMod/bin/Debug/MyWinterCarMpMod.dll**. Скопируйте его в **BepInEx/plugins/** (как в шаге 3 для игроков).


## ❓ Почему не скачать готовый мод с GitHub автора?

Автор выложил **только исходный код**, без собранного **.dll**. Я просто потратил **5 минут**, чтобы собрать его за вас.
